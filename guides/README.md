# Guides

> How-to walkthroughs for tasks that recur but don't fit a single ticket. One file per task.

## Examples of what belongs here

- Setting up local development from scratch
- Common operational procedures (rotate a secret, restore from backup, run a one-off script)
- Onboarding a new contributor
- Step-by-step recipes for tooling that has rough edges

## What does NOT belong here

- Per-ticket plans → ticket file
- Architectural decisions → `architecture/` or ticket Decisions
- Coding standards → `guidelines/`
- User-facing product docs → `DOCS` epic / public docs site

## Format

- Each file: short intro, prerequisites, numbered steps, troubleshooting, links.
- Keep them current — stale guides are worse than missing ones. If a guide is wrong, archive it (don't leave it broken).
