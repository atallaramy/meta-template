# hotfix/

Urgent, out-of-band fixes. Date-stamped, not epic-numbered.

- Filename: `HF-YYYY-MM-DD-<slug>.md`
- Template: `templates/HOTFIX.md`
- Branch: `hotfix/HF-YYYY-MM-DD-<slug>` (cut from `develop` or `main`)
- Frontmatter `epic:` still points at the relevant epic for accounting

See GOVERNANCE §1, §9 for full rules.
